# Project Plan

## Active Mode

Полуавтономная команда: агент сам предлагает и реализует короткие итерации, владелец проекта подтверждает спорные решения и production-релизы.

## Current Focus

1. Привлечь первые стабильные заявки с сайта через коммерческие сценарные страницы и статьи.
2. Основной коммерческий фокус: колонки, экшн-камеры, пылесосы и пароочистители.
3. Микрофоны держать как вспомогательное направление для съемочных комплектов, а не как ядро роста.
4. Параллельно развивать автоматизацию админки: скорость обработки заявок, быстрый контакт с клиентом, подбор комплекта, напоминания.
5. Поддерживать `sitemap.xml` из реальных данных сайта после review и QA.
6. Следить, чтобы SEO-работы не создавали дубли, тонкие страницы и неподтвержденные бизнес-обещания.
7. Отчет по источникам заявок держать в паузе до появления заметного потока лидов.

## Admin Automation Backlog

Цель: меньше ручного разбора и больше порядка в выдачах, возвратах и заявках без навязывания менеджеру готовых ответов.

1. Структурные поля заявки: сценарий, категория, даты, канал связи, доставка/самовывоз, рекомендованный комплект.
2. Статусы обработки лида: новый, взят в работу, связались, ждём клиента, конвертирован в аренду, отказ.
3. Журнал контактов по клиенту: когда писали/звонили, в каком канале, какой итог.
4. Автоматическая подсказка комплекта в админке: PartyBox-комплект, travel camera kit, WD5+SC4, Puzzi+химия.
5. Очередь “требует действия”: новые заявки старше 30 минут, возвраты сегодня, просрочки, аренды без цены/залога/адреса.
6. Напоминания по возвратам и продлениям: за день до возврата и утром в день возврата.
7. Проверка комплектности при выдаче/возврате: чек-лист аксессуаров по модели.
8. Карточка клиента: история аренд, частые категории, заметки, надежность, наличие спорных ситуаций.
9. Быстрый фильтр по основным категориям бизнеса: колонки, камеры, пылесосы, пароочистители.
10. Мини-дашборд операционной нагрузки: сколько выдач/возвратов/просрочек сегодня и завтра по офисам.
