# Project Plan

## Active Mode

Полуавтономная команда: агент сам предлагает и реализует короткие итерации, владелец проекта подтверждает спорные решения и production-релизы.

## Current Focus

1. Привлечь первые стабильные заявки с сайта через коммерческие сценарные страницы и статьи.
2. Основной коммерческий фокус: колонки, экшн-камеры, пылесосы и пароочистители.
3. Микрофоны держать как вспомогательное направление для съемочных комплектов, а не как ядро роста.
4. Параллельно развивать автоматизацию админки: скорость обработки заявок, быстрый контакт с клиентом, подбор комплекта, напоминания.
5. Поддерживать `sitemap.xml` из реальных данных сайта после review и QA.
6. Следить, чтобы SEO-работы не создавали дубли, тонкие страницы и неподтвержденные бизнес-обещания.
7. Отчет по источникам заявок держать в паузе до появления заметного потока лидов.
