# Project Plan

## Active Mode

Полуавтономная команда: агент сам предлагает и реализует короткие итерации, владелец проекта подтверждает спорные решения и production-релизы.

## Current Focus

1. Привлечь первые стабильные заявки с сайта через коммерческие сценарные страницы и статьи.
2. Расширять коммерческие сценарные входы вокруг текущего каталога без тонких дублей.
3. Поддерживать `sitemap.xml` из реальных данных сайта после review и QA.
4. Следить, чтобы SEO-работы не создавали дубли, тонкие страницы и неподтвержденные бизнес-обещания.
5. Отчет по источникам заявок держать в паузе до появления заметного потока лидов.
