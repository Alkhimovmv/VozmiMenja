# Голос бренда VozmiMenja

```text
VOICE PROFILE
=============
Author: VozmiMenja
Goal: помочь человеку быстро выбрать и арендовать технику под конкретную задачу
Confidence: medium-high

Source Set
- текущие страницы категорий и оборудования vozmimenya.ru
- страницы «Как проходит аренда», «Самовывоз 24/7» и самостоятельная бронь
- реальные условия, тарифы, комплектация и два офиса из production-каталога

Rhythm
- короткие практические фразы; одна мысль на предложение
- сначала задача и результат, затем модель и условия

Compression
- плотный текст без рекламного разогрева
- детали добавляются только когда помогают выбрать или избежать ошибки

Capitalization
- обычная русская орфография; без капслока и искусственных выделений

Parentheticals
- редко; только для точного ограничения условия или совместимости

Question Use
- прямые вопросы допустимы в FAQ и подборе
- риторические вопросы и вопросы ради комментариев не используются

Claim Style
- конкретная модель, срок, комплект, офис, действие
- обещания подтверждаются фактическим наличием или оговариваются как требующие подтверждения

Preferred Moves
- «задача → подходящая техника → что входит → как получить»
- честно указывать, когда модель может не подойти
- показывать реальный процесс, комплект и результат
- различать самовывоз 24/7 и доставку по согласованию

Banned Moves
- «революционный», «лучший на рынке», «идеальное решение для всех»
- ложная срочность, неподтверждённое наличие и бесплатные обещания
- обезличенный SEO-текст и перечисление характеристик без сценария
- одинаковый рекламный текст на всех площадках

CTA Rules
- одно конкретное действие: «Проверить наличие», «Выбрать офис», «Оформить бронь», «Подобрать комплект»
- CTA появляется после достаточного объяснения, а не повторяется в каждом абзаце

Channel Notes
- X: не является приоритетным каналом для локального проката
- LinkedIn: только для партнёрского/B2B-контекста, без массового постинга
- Email: короткое персональное предложение партнёру, один запрос, без рассылки шаблона
- VK: результат и процесс на реальной технике, локальная привязка
- Telegram: короткая практическая памятка и прямая ссылка на конкретное действие
- YouTube Shorts: результат в первые секунды, затем 2–3 шага и один CTA
```
