# B2B Email Outreach Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Оформить рабочую почту VozmiMenja и подготовить привлекательные персональные шаблоны для законного пилота B2B-коммуникации с 90 московскими организациями.

**Architecture:** Яндекс Почта используется как ручной канал отправки: сначала нейтральный запрос согласия, затем сегментное коммерческое предложение только после положительного ответа. Тексты хранятся в репозитории как единый источник и копируются в черновики Яндекс Почты; отправка и последующие контакты выполняются вручную.

**Tech Stack:** Яндекс Почта, Markdown, браузерная проверка профиля и черновиков, производственный каталог `vozmimenya.ru`.

### Task 2: Создать единый файл шаблонов

**Файлы:**

- [ ] **Step 1: Добавить правила персонализации**

В начале файла определить четыре переменные:

```text
{{company}} — название организации
{{contact_name}} — имя адресата, только если подтверждено публичным источником или самим адресатом
{{context}} — одна проверенная деталь о компании или её задаче
{{sender_name}} — Максим
```

Правила: не угадывать имя, не придумывать потребности, не менять цены и наличие, не прикладывать КП до согласия.

- [ ] **Step 2: Добавить запрос согласия**


```text

Если да, ответьте «да» или подскажите рабочий контакт ответственного сотрудника. Без вашего согласия предложение отправлять не будем.

С уважением,
Максим | Возьми меня
```

Ожидаемый результат: первое письмо не содержит цен, скидок, перечня преимуществ, вложений или рекламного баннера.

### Task 3: Создать черновики в Яндекс Почте

**Файлы:**
- Использовать: `docs/marketing/b2b-outreach-templates.md`
- Изменить во внешнем интерфейсе: папка «Черновики» аккаунта `vozmimenyarent@yandex.ru`

- [ ] **Step 1: Создать черновик запроса согласия**

Создать письмо с темой и текстом из Task 2, Step 2. Поле получателя оставить пустым. В начале темы добавить маркер `[ШАБЛОН]`, чтобы исключить случайную отправку.

Ожидаемый результат: в «Черновиках» есть `[ШАБЛОН] Можно направить предложение ответственному за аренду оборудования?`.

- [ ] **Step 2: Создать три сегментных черновика**

Создать по одному письму из Task 2, Steps 3–5. Получателя оставить пустым, а к каждой теме добавить `[ШАБЛОН]`.

Ожидаемый результат: в «Черновиках» четыре письма, ни одно не отправлено.

- [ ] **Step 3: Проверить внешний вид**

В каждом КП проверить:

```text
1. Персональное вступление занимает не более трёх строк.
2. Список оборудования легко сканируется.
3. Преимущества отделены от перечня техники.
4. Один CTA просит ответить с задачей, датами и районом.
5. Автоматическая подпись не дублирует ручную подпись из текста.
6. Нет вложений, тяжёлых изображений и нескольких конкурирующих ссылок.
```

Если автоматическая подпись добавилась, удалить ручные строки `С уважением, Максим | Возьми меня` из тела черновика и оставить системную подпись.

- [ ] **Step 4: Финальная проверка безопасности**

Убедиться, что поле `Кому` пусто во всех четырёх черновиках. Не нажимать «Отправить» и не создавать рассылку.

Ожидаемый результат: профиль оформлен, шаблоны готовы к персонализации, внешние сообщения не отправлены.
