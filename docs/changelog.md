# Changelog

Короткий журнал решений проекта. Новые записи добавляются сверху.

## 2026-08-19

- В блоговую миграцию добавлена статья-сравнение Puzzi 8/1 и Puzzi 10/1 с таблицей выбора, FAQ и ссылками на товары.
- SEO-сидер блога переведен на upsert; три growth-статьи получили FAQ-секции, а страница статьи автоматически отдает FAQ schema из markdown.
- Prerender карточек оборудования для ботов получил FAQ schema, Twitter meta и безопасную сериализацию JSON-LD.
- `robots.txt` явно закрывает `/admin/` и `/api/` для Googlebot и Yandex; категории камер и аудио получили видимый FAQ и FAQ schema.
- Карточки оборудования усилены FAQ-разметкой, ссылками на посадочные категории и блоком помощи с выбором.
- На категорийные страницы добавлены блоки выбора по сценариям с ссылками на релевантные товары и статьи.
- Smoke-проверка публичных URL теперь берет обязательные страницы и выборку URL из `sitemap.xml`; добавлены root-команды `smoke:public` и `smoke:public:prod`.
- `deploy-local.sh update` дополнен запуском `seed:blog-growth` перед генерацией sitemap, чтобы Cloud.ru не требовал ручного `tsx`.
- Добавлен режим полуавтономной агент-команды и release gate для Cloud.ru.
- Исправлена аренда на один календарный день в форме бронирования и backend-валидации.
- Fallback API URL клиента синхронизирован с backend-портом `3002`.
- Добавлена генерация `sitemap.xml` из статических страниц, оборудования и опубликованных статей.
- Добавлены 3 SEO-статьи через миграцию `seed:blog-growth`.
- На странице статьи добавлен категорийный CTA-блок с ссылками на релевантное оборудование.
- Заведен контур `seo-agent/`: база правил, очередь семантики и первый отчет.
- На главной добавлен блок свежих статей для внутренней перелинковки и переходов в блог.
- Добавлена HTML-карта сайта `/sitemap`.
- На страницы оборудования добавлены сценарии использования и FAQ.
- Добавлен клиентский helper аналитики и события для брони, телефона, мессенджеров и Avito.
- Добавлен smoke-скрипт публичных URL `smoke:public`.
