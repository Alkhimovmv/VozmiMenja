# SEO Agent

Контур для продвижения `vozmimenya.ru`: правила, очередь тем, отчеты и ритм работы.

## Принцип

SEO-машина для этого проекта не публикует контент вслепую. Она работает через короткий цикл:

1. Найти спрос или сценарий с коммерческим смыслом.
2. Проверить, нет ли уже похожей статьи.
3. Подготовить статью с внутренними ссылками и CTA.
4. Добавить статью через миграцию.
5. Перегенерировать sitemap.
6. Проверить сборку.
7. Записать результат в отчет.

## Ритм

- Еженедельно: выбрать 3-5 тем из `semantic-queue.md`.
- Перед статьей: проверить `content-checklist.md`.
- После статьи: обновить sitemap и changelog.
- Ежемесячно: смотреть старые статьи и решать, что обновлять, объединять или усиливать.

## Файлы

- `semantic-queue.md` — очередь тем и кластеров.
- `content-checklist.md` — требования к статье перед публикацией.
- `reports/` — отчеты аудитов и решений.
