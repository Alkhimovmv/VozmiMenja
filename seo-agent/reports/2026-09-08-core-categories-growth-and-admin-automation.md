# Core categories growth and admin automation

Дата: 2026-09-08

## Product decision

Микрофоны не являются основным направлением роста VozmiMenja. Они остаются вспомогательным товаром для съемочных комплектов.

Основные категории:

1. Колонки
2. Экшн-камеры
3. Пылесосы
4. Пароочистители

Параллельный продуктовый трек: автоматизация админки, чтобы быстрее обрабатывать заявки и превращать их в аренды.

## What not to do now

- Не делать районные страницы без подтвержденного спроса и операционного преимущества.
- Не плодить отдельные URL под близкие формулировки вроде `аренда GoPro` и `прокат GoPro`.
- Не делать страницы под каждую модель без уникального сценария.
- Не выводить микрофоны в центр стратегии до усиления колонок, камер, пылесосов и пароочистителей.

## Competitor patterns to keep watching

- Клининговые прокаты продают не только аппарат, но и сценарий: Puzzi, пароочиститель, химия, инструктаж, комплект.
- Камеры конкуренты часто упаковывают по срокам и аксессуарам: 1-3 дня, неделя, комплект для поездки.
- Колонки продаются через сценарии события: квартира, дача, зал, день рождения, вечеринка.

Источники для следующих итераций: Cleaning Patrol, Rentaphoto, Zoom Prokat, Pauri, Arenter, Яндекс Услуги. Перед конкретным изменением цены или оффера нужен повторный точечный ресерч по выбранной категории.

## Admin automation backlog

1. Быстрые ответы из заявки
   - Скопировать текст ответа под категорию: колонки, камеры, пылесосы, пароочистители.
   - В тексте: цена/срок, что уточнить, доставка/самовывоз, следующий шаг.

2. Подсказка комплекта
   - Вечеринка: PartyBox 320/710, при необходимости микрофон.
   - Поездка/влог: GoPro/Insta360/Osmo Pocket, крепления, аккумулятор.
   - Диван/ковер: Puzzi, расходники, подсказка по сроку.
   - Кухня/плитка/ванная: Karcher SC4, уточнение поверхностей.

3. Очередь срочных лидов
   - Группы по возрасту: до 15 минут, до 60 минут, старше часа.
   - Цель: не терять горячие заявки.

4. Конвертация contact/callback в аренду
   - Сейчас основной путь сильнее для site booking.
   - Нужно удобнее превращать любые обращения в rental.

5. Экран дня
   - Сегодня выдать, сегодня принять, просрочено, нужен контакт.
   - Использовать как главный операционный экран.

6. Напоминания по возврату
   - Сначала полуавтоматически: готовый текст для клиента.
   - Позже интеграция с Telegram/SMS, если появится стабильный поток.

7. Чеклист возврата
   - Комплектность, состояние, фото/комментарий, доплата/ущерб.

8. Мини-аналитика по категориям
   - Считать заявки/аренды по основным категориям без полного UTM-отчета.
   - Полный отчет по источникам оставить до появления потока заявок.
