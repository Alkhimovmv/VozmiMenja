### 2.2 Убрать «Загрузка статьи...» и пустые кадры после старта JS — High, 1–2 дня
- Где: `client/src/main.tsx` (`createRoot`) и `BlogArticlePage.tsx:160` (по умолчанию `loading=true`).
- **Важно:** просто заменить `createRoot` на `hydrateRoot` нельзя. Статика собирается отдельным генератором, а не теми же React-компонентами, поэтому получатся ошибки гидратации. Варианты по возрастанию трудозатрат:
  1. Встраивать данные статьи или товара в страницу при пререндере (`<script type="application/json" id="__DATA__">`) и брать их как `initialData` в React Query. Спиннера не будет, LCP и CLS улучшатся.
  2. Перейти на пререндер теми же компонентами (vite-ssg или `renderToString` при сборке) с `hydrateRoot`.
- Почему: Googlebot после рендера может зафиксировать спиннер, если API ответит медленно. CLS в блоге 0,10–0,14.
- Зависимости: вариант 1 сочетается с 2.1, вариант 2 делает 2.1 ненужным. Выбор за владельцем.
- Не сработало, если: на скриншоте Playwright через 1 с после загрузки статьи виден спиннер или CLS больше 0,1. В инструменте проверки URL в GSC отрендеренный HTML должен содержать текст статьи.
- Отслеживать: CLS и LCP в отчёте Core Web Vitals GSC через 28 дней.
