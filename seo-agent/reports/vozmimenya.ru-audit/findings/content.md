# Content Quality и On-Page SEO — vozmimenya.ru (ЧЕРНОВИК, первый проход)

Дата: 2026-11-09. Статус: черновик после статического прохода (55 URL, raw HTML пререндера + API статей). Рендер JS-версии в процессе.

## Предварительные находки
- Critical: H1 в статическом пререндере и в JS-версии расходятся (главная, /arenda-pylesosov-moskva, /arenda-moyushchego-pylesosa-dlya-divana-kovra-moskva).
- High: в пререндере статей подзаголовки H2 и списки "склеены" в абзацы, лид продублирован дважды, нет контекстных ссылок в тексте.
- High: кластеры каннибализации — "после ремонта" (3 статьи + посадочная), "камера в путешествие" (2 статьи + 2 посадочные), DJI Mic 2 (2 статьи + посадочная + карточка), Puzzi/диван (2 статьи + посадочная + хаб).
- High: шаблонные FAQ в карточках ("подходит для уборки, чистки или сушки в зависимости от модели").
- Medium: about/delivery/contact — ~95–100 слов в статике.
- Medium: блог-статьи 420–1320 слов, автор — организация, 11 из 20 без обложки, "2025" в заголовках при дате ноябрь 2026.
- Medium: обрезанные description блога с "…".
- Info: metadata_template.py site_risk=low, templated_ratio=0.0.
