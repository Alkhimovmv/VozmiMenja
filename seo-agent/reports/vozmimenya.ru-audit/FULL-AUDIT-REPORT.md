### Что в целом хорошо
- Все 64 URL из sitemap отдают 200, canonical = loc, index/follow, один H1, дублей title/description нет.
- Контент и JSON-LD отдаются статическим HTML (не пустая SPA-оболочка); http/www → один 301; честный 404.
- robots.txt корректен, AI-краулеры разрешены, есть llms.txt и Clean-param.
- NAP (телефон, адреса) согласован на всех проверенных страницах и в разметке; у точки Волжская карточка Яндекс Карт 5,0 (35–36 оценок).
- Шрифты свои, `font-display: swap`; Метрика грузится только после согласия на cookie.

### Топ-5 проблем

1. **Клиентский рендер выбрасывает пререндер** (`client/src/main.tsx` — `createRoot`). После загрузки JS статьи показывают «Загрузка статьи...» до ответа API (`BlogArticlePage.tsx:160`), вёрстка перестраивается (CLS 0,10–0,61). То, что видит Googlebot после рендеринга, зависит от скорости api.vozmimenya.ru. *Проверено в коде.*
2. **Статический HTML статей урезан**: `markdownToPlainSections()` (`client/scripts/generate-static-route-entrypoints.js:1109`) вырезает ссылки, H2, списки и таблицы и оставляет 6 абзацев. Боты без JS (OAI-SearchBot, PerplexityBot, ClaudeBot, частично Яндекс) видят обрубок без перелинковки. *Проверено в коде.*
3. **H1 главной расходится между статикой и рендером**: статика — «Техника напрокат в Москве — на сутки и на месяц», рендер (что индексирует Google) — «Возьмите технику на день а не на годы», без ключевых слов (`HomePage.tsx:273`). *Проверено.*
4. **Автопрокрутка на 3 категориях** (`CategoryPylesosyPage`, `CategoryAudioPage`, `CategoryCamerasPage` — `scrollIntoView` через 300 мс): H1 и вводный текст уезжают за экран, CLS 0,49–0,61 на `/arenda-pylesosov-moskva`. *Проверено в коде.*
5. **Рейтинговая разметка с риском санкций**: AggregateRating 5,0/36 в глобальном графе на всех 64 страницах, хотя виден только на странице Волжской. В `server/src/routes/prerender.ts:206` захардкожен вымышленный рейтинг 4,9 / 412 (сейчас не отдаётся, но `nginx-prerender.conf` включит его). *Проверено в коде.*

### Топ-5 быстрых побед

1. Удалить хардкод `aggregateRating 4.9/412` из `prerender.ts` (10 мин).
2. Убрать автопрокрутку на 3 категориях или делать её только при `#catalog` в URL (15 мин).
3. Вернуть ключ в видимый H1 главной: например, «Техника напрокат в Москве» в H1, слоган — в подзаголовок (15 мин).
4. `aria-label`/`<label>` для выбора оборудования, дат и времени на /booking (30 мин).
5. Компактная cookie-плашка на мобильном (сейчас 169 px из 844) (30 мин).

## Technical SEO — 82

- Medium: нет HSTS/CSP/X-Content-Type-Options/Referrer-Policy — ограничение GitHub Pages; решается CDN/прокси или отдачей через Nginx на Cloud.ru.
