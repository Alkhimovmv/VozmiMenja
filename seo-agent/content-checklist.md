# Content Checklist

## Перед Написанием

- [ ] Есть основной запрос или сценарий пользователя.
- [ ] Понятно, какая категория или товар получает трафик.
- [ ] Проверено, что такой статьи еще нет.
- [ ] Понятен CTA: каталог, конкретная карточка, звонок или консультация.

## Структура Статьи

- [ ] Один понятный H1.
- [ ] Вступление отвечает на intent пользователя.
- [ ] Есть практические подзаголовки H2/H3.
- [ ] Есть таблица, список выбора или пошаговый блок, если тема это просит.
- [ ] Есть минимум 3 внутренние ссылки.
- [ ] Есть финальный CTA к аренде или консультации.

## Качество

- [ ] Нет выдуманных фактов, цен и характеристик.
- [ ] Нет переспама ключевыми словами.
- [ ] Текст полезен сам по себе, даже если пользователь не оставит заявку.
- [ ] Даты обновляются только при реальном изменении материала.
- [ ] Slug латиницей, в нижнем регистре, через дефис.

## Публикация

- [ ] Статья добавлена через миграцию или админку.
- [ ] `published = 1` только после проверки.
- [ ] Sitemap пересобран.
- [ ] `npm run typecheck` прошел.
- [ ] `npm run build` прошел перед релизом.
