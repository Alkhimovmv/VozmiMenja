# 2026-09-07-cwv-micro-backlog

От: Product Lead
Кому: Frontend UX
Статус: dispatched

## Контекст

В `.agents/board.md` открыт пункт: сформировать backlog микроулучшений по Core Web Vitals. Это не задача на большой редизайн. Нужен короткий список безопасных улучшений, которые повышают скорость и стабильность публичных страниц.

## Задача

Провести frontend-аудит потенциальных микроулучшений Core Web Vitals и подготовить backlog.

Готово, если:

- проверены главная, категории, карточка оборудования, блог и статья;
- найдено 5-8 микроулучшений с оценкой эффекта и риска;
- отдельно отмечены quick wins без визуального риска;
- отдельно отмечены задачи, которые требуют метрик Lighthouse/PageSpeed или production-данных;
- для каждой задачи указан владелец: Frontend UX, SEO Content, Backend Automation или QA Release.

## Ограничения

- Не делать заметный редизайн.
- Не менять внешний вид карточек и CTA без отдельной задачи.
- Не ломать SEO meta/schema.
- Не трогать production.

## Ожидаемый эффект

Собрать понятный список коротких performance-задач, из которых Product Lead сможет выбрать 1-2 на следующую итерацию.

## Проверки

npm run typecheck --workspace=client
npm run build --workspace=client
