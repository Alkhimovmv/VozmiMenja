# Handoffs

Сюда можно добавлять короткие передачи между агентами, если задача начата в одном чате, но должна продолжиться в другом.

## Формат файла

```md
# YYYY-MM-DD-short-topic

От: Frontend UX
Кому: Backend Automation
Статус: blocked | ready | needs-review

Контекст:
Что сделано:
Что нужно:
Риски:
Файлы:
Проверки:
```

Файл можно удалить или перенести в changelog после закрытия задачи.
