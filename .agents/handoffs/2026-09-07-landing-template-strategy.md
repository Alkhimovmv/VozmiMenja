# 2026-09-07-landing-template-strategy

От: Product Lead
Кому: SEO Content
Статус: dispatched

## Контекст

В `.agents/board.md` остается следующий growth-пункт: продумать шаблон для посадочных страниц под районы/сценарии использования. Это нельзя превращать в массовую генерацию страниц: сначала нужен шаблон и критерии пользы, чтобы не плодить тонкий SEO-контент.

## Задача

Подготовить продуктово-SEO шаблон посадочной страницы для районов Москвы и сценариев использования.

Готово, если:

- описаны 2 типа страниц: районная и сценарная;
- для каждого типа есть структура блоков, intent, CTA и внутренняя перелинковка;
- есть критерии, когда страницу можно создавать, а когда нельзя;
- есть 3-5 приоритетных примеров страниц-кандидатов;
- отдельно перечислены данные, которые нужны от бизнеса: районы доставки, реальные кейсы, условия, оборудование, ограничения;
- нет готовой пачки URL к публикации без проверки.

## Ограничения

- Не создавать десятки страниц.
- Не менять URL-структуру.
- Не публиковать AI-контент без ревью.
- Юридические условия и цены не переписывать без подтверждения владельца.

## Ожидаемый эффект

Подготовить безопасный путь к локальному SEO: страницы должны помогать клиенту понять доставку, наличие, сценарий аренды и следующий шаг к заявке.

## Проверка Product Lead

Я приму результат, если из него можно выбрать 1-2 страницы MVP без SEO-риска и без спорных обещаний.
