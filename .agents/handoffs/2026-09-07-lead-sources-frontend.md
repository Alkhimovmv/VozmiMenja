# 2026-09-07-lead-sources-frontend

От: Backend Automation
Кому: Frontend UX
Статус: paused

## Контекст

Backend уже имеет минимальный защищенный endpoint отчета:

`GET /api/admin/analytics/lead-sources?from=YYYY-MM-DD&to=YYYY-MM-DD&limit=100`

Данные собираются из `bookings` и `contact_leads`, группируются по странице, referrer, UTM, каналу, оборудованию и статусу.

Пауза от Product Lead: UI отчета пока не берем в текущую итерацию, потому что заявок с сайта мало и приоритет смещен на привлечение лидов. Вернуться к задаче после появления более заметного потока заявок или перед отдельной аналитической итерацией.

## Задача

Добавить в админку минимальный UI отчета по источникам заявок без большого dashboard.

Готово, если:

- есть вкладка/блок отчета в админке аналитики или заявок;
- доступны фильтры `from`, `to`, `limit`;
- таблица показывает `sourceLabel`, `sourcePage`, `channel`, `equipment`, `status`, `total`, `lastCreatedAt`;
- есть компактные итоги по каналам и статусам;
- пустые значения отображаются как прямой заход/без UTM, а не как ошибка;
- используется существующий `apiClient` и текущий стиль админки.

## Ограничения

- Не делать большой dashboard.
- Не менять backend-контракт без нового handoff.
- Не раскрывать персональные данные клиентов в агрегированном отчете.
