# Agent Board

Эта доска нужна как входная точка для задач, которые агент-команда может брать в работу.

## Working Chats

- `Product Lead`: главный штаб, приоритеты и решение, что берем дальше.
- `Frontend UX`: сайт, админка, формы, карточки, мобильная конверсия.
- `Backend Automation`: API, база, заявки, уведомления, Cloud.ru deploy-устойчивость.
- `SEO Content`: блог, посадочные, sitemap, schema, перелинковка.
- `QA Release`: проверки, smoke, регрессии, release checklist.

Перед стартом отдельного чата агент читает свой файл из `.agents/roles/`.
